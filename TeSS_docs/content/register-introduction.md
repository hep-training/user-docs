# Introduction

```{admonition} Restricted to registered users and about content visibility
By default, content registration is only available to [registered users](./user#register).

Then, any registered content has an 'Approval Status' set by default to 'Requested' which means that the resource is not yet public. It must pass under a [curation](./curation) process to be accepted and finally be open to the public.
```

There are two ways to register training materials or events for display in HEP Training.

## Automatically

If you have a good amount of training resources to submit, and you want them to be automatically up-do-date, then this is how you should do:

1. First, get to know the structure that your training's metadata needs to comply with, see [structured data types](./structured-data-types).
2. If this is not possible or too complicated, please have a look at the [sources](./sources) page.

If you wish to exchange content between TeSS instances, see [exchange](./exchange)

## Manually

If you have few trainings to register, see how to '[register events and materials](./manual-events-materials)'

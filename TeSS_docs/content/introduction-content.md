# Introduction

```{admonition} Restricted to registered users and about content visibility
By default, content registration is only available to [registered users](../accounts/user#register).

Then, any registered content has an 'Approval Status' set by default to 'Requested' which means that the resource is not yet public. It must pass under a [curation](../advanced/curation) process to be accepted and finally be open to the public.
```

Training resources (events and materials) may be added to HEP Training to reach bigger audiences, increase impact and bolster event attendance. Registering events and training materials makes them more findable in a variety ways to various user bases.

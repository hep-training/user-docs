# Automatically

```{admonition} Restricted to registered users and about content visibility
By default, automatic content registration is only available to [registered users](../accounts/user#register).

Then, any automatically ingested resource has an 'Approval Status' set by default to 'Requested' which means that the resource is not yet public. It must pass under a [curation](../advanced/curation) process to be accepted and finally be open to the public.
```

HEP Training features several options for automatically 'harvesting' resources from external sources.
This can be helpful if you are maintaining a large collection of events and materials that changes frequently.

See what kind of website / data HEP Training can ingest: [Structured data types](./structured-data-types)

## TL;DR

- Add schema.org formatted metadata in the web page source code of your training material/event (see example in [Structured data types](./structured-data-types#example) page)
- If you want your entire website to be scraped, your website should contain a [sitemap](./structured-data-types#sitemaps)
- Register in HEP Training a new [content provider](../accounts/content-provider) and [source](./sources) and wait for an admin's approval
- Or, contact us at <contact.heptraining@cern.ch> to discuss how to register your content automatically in HEP Training

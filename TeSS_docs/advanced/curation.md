# Content Curation

```{warning} Prerequisites to be able to curate resources

- Be an [administrator](/roles#administrator), or [curator](/roles#curator), or [space administrator](/roles#space-administrator) (generally speaking *curators*). Space administrators can only see resources from their space.

```

## How are training resources curated in TeSS?

Any added training material or event (either [manually](./manually) or [automatically](./automatically)) will be **by default** subject to verification and thus, not publicly shown in your TeSS instance. Your resource will be marked with an 'Approval status' set to 'Requested', as shown below:

```{image} ../images/content/material_requested_view.png
:alt: A material with requested view
:width: 600px
:align: center
```

*Curators* can then have access to a dashboard to review the newly registered resources by accessing the dashboard for curation, which can be found by clicking on the dropdown menu of the user profile on the top-right of the page once logged in > 'Curate resources'.

```{image} ../images/content/curate_button.png
:alt: Curation button
:width: 300px
:align: center
```

In the dashboard, *curators* can filter resources by Type (material, event), User, [Provider](/content-provider), [Space](/spaces), and Approval Status. 'Approve All Filtered' and 'Reject All Filtered' buttons can be found at the bottom of the page to approve or reject all shown/filtered resources. For example, if you have a new Content Provider adding thousands of already curated materials, you can filter the list by its name and approve them all in a few clicks only.

```{image} ../images/content/curate_resources.png
:alt: Curation dashboard
:width: 600px
:align: center
```

## How to revoke the approval status of a resource?

A *curator* may have misclicked the 'Approve' button, they may come back to their decision by editing the resource.

1. Go in the resource's page
2. Click on the Edit button on the top-right
3. Scroll all the way down
4. Change the 'Approval status' field to 'Requested'
